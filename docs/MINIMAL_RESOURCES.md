# 必要资源模式

安装器可选择完整资源或实验性的仅必要资源。精简模式使用既有斗牛一及莲花古城资源依赖闭包，保留运行文件、索引、签名和其他尚未判定可省略的文件。共享 IoStore 容器只获取覆盖依赖范围的完整 CDN 下载块。每个下载块经过解压及 SHA256 校验，文件保留原逻辑大小，NTFS 稀疏区域不占用对应物理空间。

固定客户端版本为 448DAE34A9D16C88。完整模式约下载 31.46 GB，精简模式约下载 19.66 GB，写入数据约 22.12 GB。NTFS 分配单位和补丁运行环境还会增加磁盘占用。Windows 属性中的逻辑文件大小仍约 34.81 GB。

精简依赖范围为斗牛一、莲花古城和旧依赖方案收集的皮肤。其他地图或皮肤需要完整模式。首次精简安装默认选择莲花古城，已有用户设置由安装器保留。此模式尚未完成完整 CDN 下载及游戏内验收。

再次打开安装器并选择相同目录、相同模式可续传或修复。选择完整模式可补齐资源。GitHub 更新保留安装目录中的资源模式记录与游戏资源，更新包同时携带两种资源验证清单。

验证覆盖本地真实 HTTP 下载的稀疏还原、重复安装免下载、损坏块修复、精简到完整模式补齐，以及五个真实 CDN 块的下载、解压和哈希校验。完整资源依赖闭包的运行覆盖仍待验收。
