# 拟人人机 Bot-only v1 使用说明

双击 **`F:\valoranttrainer\启动本地服务器控制台.cmd`**。浏览器打开本机控制台后，进入 **人机乱斗 → 打开拟人人机详细设置**，也可直接打开 [人机设置](http://127.0.0.1:8792/#human-bots-settings)。设置地图和固定人机名单，确认“使用拟人人机”后，点击右上角 **开始训练**；结束时点击 **结束训练**，或在游戏中按 **F10**。

这是本地个人乱斗的人机版本。设置会保留，再次打开不会自动恢复初始人数、地图或参数；英雄技能不属于本版的人机能力验收。

## 固定人机名单

每条名单独立保存英雄、段位预设和详细战斗参数。选择“新英雄”“初始预设”，点击 **添加人机**；列表中的 **删除** 只删除该条。名单可保留 1–29 个人机，总人数自动等于名单人数加你。英雄不重复，也不与自己的英雄重复；开局和死亡重生都不重新抽英雄。

点击某条的 **详情** 编辑这个人机。参数和草稿按持久条目身份保存；重排和死亡不会把参数转给另一个英雄。添加、删除、重排或更换英雄会保存为下一局名单，需要手动重启对局；当前局仍使用开局名单，界面会区分两者，不自动重启。

旧设置首次读取时会保留地图、无限子弹等偏好，按固定顺序生成名单并保留原来每个人机的有效参数。首次保存或开始训练才持久化转换。

## 原生观战

对局开始后，点击名单中的 **观战**，或在详细设置中点击 **观战此人机**，跟随这条名单对应的英雄。游戏窗口获得输入且菜单关闭时，默认 **鼠标左键切下一个、右键切上一个**；使用游戏原生目标顺序。WebUI 根据客户端实际观战对象显示英雄和已采用的参数，不按最近一次点击猜测目标。

被观战的人机死亡时会显示等待重生，并在同一条目重生后继续跟随。点击 **返回自己** 结束观战。观战期间自己不参与人机的目标选择和双方伤害，退出后恢复；进入观战不会保存未提交的参数草稿。

如果修改了英雄或名单结构，尚未以相同条目和英雄在本局出场的人机暂不能观战；手动重启对局后可用。若界面显示等待确认，应以实际视角和客户端状态为准。

## 段位预设和个人参数

内置 **25 个细分段位预设**，从黑铁 I 到赋能（Radiant），每档调整瞄准、识别、压枪、注意力、身法执行等 **61 项**控制。它们是可编辑的强度梯度，尚未用真人统计校准，不能视为精确段位复现。旧 9 组风格仍保留兼容，已有值不会被新预设替换。

在名单中为一个人机选择预设，再点 **应用**，会替换这条已保存的个人参数。其他人机不变；未保存草稿仍需自行保存或放弃。填写名称并点 **保存此人机为预设**，可把这条已保存的参数加入自定义库，供其他条目复用。正在被引用的预设不能删除。

在“常用设置”或“全部细项”搜索中文名称。启用拟人人机后，旧“人机水平”的基础滑条不参与行为，应在详细设置修改。每项展开“范围、条件与生效说明”，可查看含义、单位、合法范围、默认值、依赖和数据来源。当前配置有 **2392 项**，其中语义常量和来源不可靠的项目保持只读。

| 编辑范围 | 作用与优先级 |
| --- | --- |
| 风格默认 | 修改所选风格；既有全局、分布和单人覆盖仍优先 |
| 全局覆盖 | 固定值作用于所有人机；选择固定值会同时删除该项个体分布，单人覆盖保留 |
| 个体分布 | 为每个人机独立确定范围内的能力，优先于风格和全局值 |
| 单个人机 | 只改所选名单条目，优先级最高；可用固定值、范围或继承 |

完整顺序为：**内置默认 → 条目预设及其修改 → 全局覆盖 → 个体分布 → 条目个人覆盖**。新增条目和“应用预设”默认保存个人快照，因此全局值不会暗中盖过这条快照；需要继承时，在相应个人细项恢复继承并保存。共享查询预算等全局参数不支持分布或单人覆盖，面板会说明原因。范围按对局种子、持久条目身份和参数确定，重排及同局死亡重生不重抽；短时失误和动作波动另行设置。

例如，要只改变一个英雄的一次定位速度：点击该条 **详情**，选择“单个人机”，搜索“一次定位最大转向速度”，选择固定值并填写合法数值，再点 **保存修改**。每行的“配置预览”和“来源”用于确认最终覆盖；预览尚未读取时，继承数值会留空，避免沿用另一条的值。

**名单操作、预设应用和启用开关会直接保存；细项修改需点“保存修改”。**“恢复当前范围继承”先生成待保存修改，只清所选层；还要保存才会生效。跨项校验失败会保留草稿并拒绝该批，不自动改动其他能力。

## 怎样确认修改已采用

面板分别显示 **保存版本、客户端接收、行为采用**。保存成功表示配置已保留；客户端接收表示已收到配置；**行为模块已确认当前配置**才表示本轮行为消费者已采用。同一名单内的战斗参数从后续决策开始采用，不必等下一局；名单结构改变或尚未启动时会显示等待应用。

这些状态都不代表某次拉出、开枪、命中或换弹已经完成；动作仍取决于当时感知、空间、武器和真实角色反馈。每行的配置预览也不是实测枪法读数。

## 当前精度和来源限制

2026-11-07已修正无目标巡逻与预瞄的计时冲突：转移预瞄点不会延长搜索停留，游走会保持当前路线；全图锚点不再直接充当视线目标。行进时优先看原路线中有视线证明的拐角，缺证明时只沿下一路径段看。丢失目标后的短暂停留仍由原设置控制，记忆保留不会持续锁住旧位置。见 [本轮验证](../work/humanlike-bots/no-target-navigation-20261107/README.md)。

- **12 项来源锁定**：落地听觉2项、其他战斗声2项、消音听距倍率1项、近战3项、首轮未命中后的动作权重4项。没有命中回执不等于确认未命中；角色落地也不等于听到了落地声。
- 脚步和枪声由已观测的原生请求或发射证据形成带误差的逻辑声音线索，尚未覆盖全部音频播放路径。
- 感知、视角、决策和原输入按各自有效采样节奏运行。更频繁调用决策不会凭空增加转角；同一份视角样本只重发同一绝对朝向请求。毫秒参数不保证逐毫秒更新，显示的小数也不等于实际控制精度。
- 视觉“露出比例”是眼、胸、左右肩最多4个近似点的可见比例，**不是模型露出面积或屏幕像素比例**；还须满足视野、遮挡、采样和识别条件。

每项已有的“按条件可用”和数据来源说明，应与当前实际动作一起判断；本版本不据参数数值宣称真人段位或所有地图、武器、动作都已验证。
