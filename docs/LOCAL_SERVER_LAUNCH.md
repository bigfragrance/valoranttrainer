# 本地服务器拟人人机入口

这是原客户端研究项目的独立本地服务器入口，使用现有
`local-server-candidate` 后端和本机控制台。原来的
`启动训练控制台.cmd`、`.\dev.ps1 play`、8790 端口和原设置继续保留。
本入口不代表完整拟人人机要求已验收。

## 启动和退出

部署到项目根目录后，双击 **`启动本地服务器控制台.cmd`**，打开
<http://127.0.0.1:8792>，再点击“开始训练”。也可在项目目录运行：

```powershell
.\dev.ps1 play-local
```

`play-local` 同时请求开始训练。仅检查入口和配置、不创建或改写设置、不启动
控制台或游戏时，运行：

```powershell
.\启动本地服务器控制台.cmd --check
```

脚本实际交给现有控制台的参数为
`--backend local-server-candidate --port 8792 --settings-file <独立设置绝对路径>`。
它不会自动构建模块；实际开始仍经过原来的构建身份、地图、配对归属和
无账号检查。控制台只监听 `127.0.0.1`，并由现有监督器启动自有 host/client。

在 WebUI 点击停止或在客户端按 F10，沿现有流程先结束 client，再关闭
host。退出控制台可按 Ctrl+C。重复运行只会在后端、项目身份和设置文件
均一致时复用已开的控制台。如果 8792 仍由临时测试设置或其他后端占用，
现有控制台会明确拒绝复用；入口不会擅自关闭那个服务或切换其配置。

## 配置如何保留

稳定设置文件是：

```text
F:\valoranttrainer\.local\controller\local-server-candidate\humanlike-bots.json
```

首次使用，在内存中按已有迁移器读取
`.local/controller/config.json` 的保存偏好，并创建一个新的 schema3 文件。
只将初始模式设为个人乱斗、地图设为 Ascent、总人数设为 12（含玩家本人）、
拟人人机设为启用，并开启原生脚步请求的听觉模型。脚步线索仍受距离、遮挡、
延迟、误差及个体能力设置影响；落地听觉保持原默认关闭。武器、皮肤、原人机偏好和无限子弹等其他保存值按原迁移器
继承，原文件字节保持不变。本次检查的原偏好为无限子弹开启；实际首次使用
会读取那时的保存值，不把当前测试值或本说明的数值写死在代码里。

设置文件仅首次创建，使用原子发布且不替换已存在的文件。之后从这个独立
文件读取，WebUI 保存继续使用现有的版本校验和原子写入。再次打开不会把
人数、地图、人机开关、无限子弹或参数重置成初始值，也不会重新复制原设置。
已存在但损坏或版本不正确的独立文件会报错并保留原内容。

此入口不读取 `settings-fixtures`、历史配对配置、临时 WebUI 草稿或开发
覆盖值。直接手写 `training_server.py --backend local-server-candidate` 而
省略 `--settings-file` 仍使用该后端原来的 `config.json`；那是另一个独立
存储，不会自动变成本入口的 12 人拟人人机配置。

启动快照、日志和控制台记录沿用候选目录的 `sessions/`、`logs/`、
`server-8792.json`，实际配对位于 `.local/local-server/pair-<时间>/`。
本项目的临时目录、Python 缓存和游戏缓存均重定向到 F 盘项目目录。
本入口不打包或复制游戏资源。

## 尚未完成验收的关键范围

以下按当前源代码能力声明和 `docs/IN_PROGRESS.md` 最新接续点列出。
配置能保存、模块能编译、消费者确认版本，分别都不等于动作已在游戏里执行。

- **首轮失手后的分支**：仍缺可感知的整次原发射（含全部弹丸、穿透）的
  Miss 完结证据，四项 FirstMiss 权重继续锁定；不能把“没收到命中”当失手。
  可见原碰撞建模的 Hit 也要与原生命、发射和已获视觉目标关联，不代表原命中音已播放。
- **声音和近战**：其他战斗声、消音倍率、近战攻击读回仍缺可靠消费者。
  已观测脚步/落地请求的逻辑传播模型不能称为覆盖了所有原音频可听路径。
- **跳拉和换弹闭环**：真实起跳、越过掩体、落地和撤回需在启用配置下逐项
  实测；前次 JumpEnabled=0 的局不能提供起跳证据。换弹请求、正换弹状态、
  弹匣/储备变化与许可恢复的完整相关性仍需最终版本验证。
- **地图与动作覆盖**：Ascent 的已验证几何不替代全部地图的掩体、退路、
  高低差和多目标暴露验证。大拉、小拉、慢蹭、蹲拉、肩探、广西步、死区射击、
  Poppin swing 及各种中断/释放输入仍需分别提供实际输入、原状态和结果证据。
- **参数与段位风格**：2353 项目录不是2353项实际行为验证。仍需逐组证明
  参数双向变化确实影响对应行为、跨重生稳定、个体覆盖不暗改其他人；预设没有
  真人统计校准，不能声称精确复刻某段位。
- **网络生命与完整技能**：多次玩家死亡重生后的原结束时钟分支、全部英雄技能
  的本地服务器迁移仍未收口。烟闪和技能状态对感知的覆盖也需逐技能验收。
- **规模和用户实操**：30 人长期帧耗/查询预算、卡顿原因和全部地图武器情境，
  玩家手动开火体验、原结果 UI 和动画画面仍需在最终发布版本验证。

这份入口候选只验证配置初始化、持久保存和调用参数，不新增任何游戏行为
完成声明。部署与实际运行由主开发流程审阅后进行。
