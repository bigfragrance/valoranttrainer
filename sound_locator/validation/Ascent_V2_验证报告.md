# 声迹 V2：Ascent 实录验证

日期：2026-11-09。当前结果是一个可运行的研究版本：方向估计明显改善，支持已知视角、全图候选区域和数量可增长的轨迹假设；**尚不能保证恢复每个重叠声音，或把每条移动脚步可靠地唯一定位到小地图坐标**。

## 实际执行了什么

- 启动国际服原客户端的自有离线 Ascent 场景，没有连接官方对局服务器。
- 使用原 `AresSoundHandler.OnCharacterGroundSound` 路径播放脚步，执行原地面/胶囊/移动段验证，经过 SurfaceType、Perspective、Occlusion 等原处理。不是只运行合成音频测试。
- 声源位置沿受验证点移动，监听器可转头或原 `TeleportTo` 离散平移；**演员本身没有自然行走**，不能称为完整实战 NPC 行走验收。
- HRTF 设置经原 API 读回开启；没有独立证明完整 DSP/插件链。
- 音频来自真实 WASAPI 回环；玩家相机姿态约21Hz采样。声源真值单独保存，推理只使用音频、背景、listener pose、地图和已冻结模型。
- 原默认训练模块在实录后恢复并通过哈希检查。程序运行本身不访问游戏进程。

采集与边界：[原客户端录音证据](../docs/ascent-recording-evidence.md)；地图：[导航图说明](../maps/README.md)。

## 独立未见角度：单源脚步

24个方向校准；最终测试为8份独立录音、24次脚步，角度偏移7.5°，未参加模型训练或选择。按**音频自身的 onset**提取事件，检测24/24，无多余 burst。方向网络在最终评估前后保持相同哈希。

| 方法 | 首选角度中位误差 | 90分位误差 | 平均误差 | ≤30°事件数 |
|---|---:|---:|---:|---:|
| 实测模板 DirectionField | 1.5° | 49.5° | 11.25° | 21/24 |
| 新方向神经网络 | 2.5° | 7.5° | 3.96° | 24/24 |

改进主要是减少大角度误判，中位数并非所有指标都更优。只有8份录音，不能把24/24称为通用准确率100%。开发留出组仍出现过100°和110°的两次误判。

完整数据：[独立事件对照](learned-ascent-onset/final-unseen-event-comparison.json)。模型及方法：[learned-audio.md](../docs/learned-audio.md)。

## 连续转头、移动源和重叠源

下面是同一整合程序的受控24秒场景。表中角度采用**离真值最近的方向候选**；位置采用**离真值最近的轨迹主峰代表节点**，均是偏乐观的诊断指标，不能证明源身份或轨迹编号正确。程序运行时看不到这些真值。

位置列启用了独立训练的弱脚步距离模型。该模型没有用这些轨迹的真值训练。

| 场景 | 原触发 / 检出burst | 角度误差中位 / P90 | 位置主峰误差中位 / P90 |
|---|---:|---:|---:|
| 固定监听器、移动脚步源 | 53 / 51 | 2.13° / 7.05° | 3.82m / 11.78m |
| 转头、固定脚步源 | 53 / 52 | 2.62° / 9.46° | 0.81m / 2.97m |
| 两个移动脚步源 | 102 / 74 | 6.76° / 21.48° | 4.35m / 12.52m |
| 非共线平移监听器、固定源 | 53 / 52 | 2.45° / 5.88° | 1.13m / 2.37m |

两源102次触发只对应74个检测burst，一部分同时/相近起声被合并。该实验有最多3条候选轨迹、10次最近轨迹ID变化；不能称为稳定识别两个真实个体。无固定3条上限不意味着源数估计已经准确。

所有上述帧仍被程序标为位置未充分集中。保守候选区域可能延伸几十米；其保持真实位置附近的支持，但“范围包含真值”不等于精确定位。界面默认不把宽分布的代表节点画成确定敌人。可选候选路径也只是可能解释。

加入弱距离前，固定监听器场景的代表节点会偏到26～31m外；全图滤波修复了粒子耗竭、保留近场可能性，但纯方位本身仍无法确定距离。非共线平移提供约2.78m实际基线和25.47°方位变化，才有额外测距几何信息。单纯转头没有这个基线。

逐事件报告：[移动源](ascent-range-tracking/moving_source-evaluation.json)、[转头](ascent-range-tracking/turning_listener-evaluation.json)、[两源](ascent-range-tracking/two_sources-evaluation.json)、[非共线平移](ascent-range-tracking/noncollinear_listener_motion-evaluation.json)。

## 距离模型的独立检验

新增36份多距离校准与7份中间距离留出，实际位置约1.89～20m，所有点由原引擎验证。12m/-75°没有找到合法点，明确跳过。108次校准触发中只关联91个检测事件，远声漏检没有剔除隐瞒。

独立留出21次触发全部检测到，自动类型/域检查后返回20次距离线索：绝对距离误差中位2.12m、P90 3.49m，宽启发区间覆盖17/20。似然保留0.70的平坦底，只作为弱约束；不是响度反比例测距。

距离模型默认不启用；设备、音量和HRTF需一致。未知声音、域外事件和未确认音频链拒绝。多成分窗口不会把同一总能量距离分布套给每条声源。

[距离留出报告](range-ascent/holdout.json)；[模型范围](../docs/range-audio.md)。

## 地图、数量和软件检查

- 真实Ascent导航查询：36,288次投影、7,125次路径查询，保留6,816条完整原路径，生成13,911节点、18,772边；路径只走原边，不用近邻直线跨墙。
- 全图节点保留正支持，包含静止/移动模式；前后/远近多解不强制压成一个点。候选区域是模型解释，不是统计置信区间。
- 轨迹列表没有固定数量上限。8源时频不重叠的合成音频检查和8条动态轨迹检查通过；实际多源录音目前只测了两个源。
- 当前68项算法、地图、事件、模型、输入同步、GUI生命周期和路径约束测试通过。声学方向网络推理约0.62ms/160ms事件窗；完整24秒场景分析约4～6秒（本机并行测试量级），不是端到端延迟。onset需约140ms等完整窗，另有采集、姿态和显示延迟。
- 初版粒子滤波的失败记录保留；没有用“启动成功”“非零PlayingID”替代听音和定位检查。
- 打包版 `SoundMapLocator.exe` 已实际打开并通过实时loopback启动/停止测试；随后启用距离实验与候选路径，完整分析24秒移动脚步录音，界面显示51个事件、有效距离弱提示、位置未收敛且无运行异常。

## 未完成的准确性范围

其他英雄/表面、枪声/技能、其他地图、自然NPC行走、真实在线比赛、复杂楼层/遮挡/门、多种来源同时重叠、长时间身份保持，以及真实硬件时间同步均未充分验证。当前不能承诺“无限个声源全部恢复”，也不能把候选轨迹当作敌人精确位置。

研究依据：双耳声音与自身转动可以联合消歧，但不自动给出距离；两通道分离多源需要额外稀疏性等条件。[主动双耳定位研究](https://www.sciencedirect.com/science/article/pii/S0921889015301780)、[原DUET在线分离论文](https://math.umd.edu/~Rvbalan/PAPERS/MyPapers/onlineduetICA2001.pdf)。这些论文支持方法方向，不替代本程序的游戏实测。
