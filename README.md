# VALORANT Trainer

Windows 本地训练项目，提供架点练习、拟人人机、本机 WebUI、资源下载安装器和 GitHub Releases 更新。

## 安装与运行

在 [Releases](https://github.com/bigfragrance/valoranttrainer/releases/latest) 下载 `ValorantTrainer-Setup-20261115.exe`，选择空间充足的独立目录。安装器会从固定版本 CDN 下载约 31.46 GB 资源，支持断点续传和校验修复。安装完成后双击安装目录的“启动训练器.cmd”，在本机控制台开始训练。

Windows 10/11 64 位，建议为资源、缓存和更新预留至少 40 GB。安装包包含 Python 运行环境。当前资源版本固定为 `448DAE34A9D16C88`。

## 架点练习

- 持续模式允许配置多个拉出点，随机选择点位，所有点共享最小拉出间隔。
- 波次模式允许编辑多个波次和敌人列表，同一波英雄不重复。每名敌人的随机时间从本波开始计时。
- 每名敌人可设置大拉、小身位拉出、静步、大拉后蹲、小拉后蹲，以及是否开枪。
- 本波敌人全部死亡或撤回后进入下一波，最后一波结束后停止。阻塞敌人在预定时间后 30 秒收尾。暂停会冻结计时。

## 更新

安装目录双击“检查更新.cmd”，或在安装器中选择已有安装目录后点击“GitHub 更新”。更新前关闭训练控制台与游戏。更新器从本仓库的正式 Release 获取清单，核对版本、资源版本、大小、SHA256 和文件清单，保留用户配置与资源，替换失败时恢复备份。

发布渠道与操作见 [GitHub 更新说明](docs/GITHUB_UPDATES.md)。

## 源码

`native/` 包含 C++ 原生模块，`tools/` 包含 Python 控制、构建和安装工具，`webui/` 为训练控制台，`sound_locator/` 为声音地图研究工具。源码开发入口为 `dev.ps1`，已有本地开发环境可使用 `play`、`play-local`、`status`、`test`。

开发构建需要匹配的本地客户端、Python、MSVC 和 Windows SDK，并在 `project.json` 设置本机路径。公开仓库排除了游戏客户端、资源容器、账号文件、本地配置、缓存和运行日志。安装器构建还需要本地生成的固定版本资源计划及已验证原生模块。
